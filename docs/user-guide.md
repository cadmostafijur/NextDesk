# NexDesk User Guide

## First launch

1. Install NexDesk for Windows.
2. Enter a device name.
3. Your **NexDesk ID** appears on the Home screen (format `NXD-XXXX-XXXX-XXXX`).
4. Copy the ID to share with someone who should request access.

Your ID is only an address. Others still need your acceptance (or unattended access you configured).

## Connect to another PC

1. Open **Connect**.
2. Paste the remote ID.
3. Choose View only or View + control.
4. Click **Request connection**.
5. Wait for the remote user to accept.

## Accept a session

When someone connects, a dialog shows their name, ID, and requested permissions. **Reject** anything unexpected.

While sharing, a clear banner indicates your screen is shared. Use **Disconnect** to end immediately.

## Unattended access

Off by default. In **Security**, enable only if you need to reach this PC when nobody is present. Choose a strong password and revoke it when finished.

## Troubleshooting

| Symptom | What to try |
|---------|-------------|
| Offline | Ensure the NexDesk network service is reachable (Settings → signaling URL). |
| Device not found | Confirm the ID and that the other PC is online. |
| No video | Grant screen-capture permission when prompted. |
| No control | Session may be view-only; ask the host to grant control. |
